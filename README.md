# JavaScript Flashcards

A simple interactive JavaScript study project built as a flashcard-style learning page. The app helps users review key JavaScript concepts such as functions, arguments, arrays, methods, booleans, and parameters in a visual and easy-to-use format.

## Project Overview

This project includes:
- A responsive layout for learning cards
- Interactive flashcard buttons
- JavaScript-powered toggling of definitions
- Styled UI with custom colors, fonts, and modern card effects

## Features

- Click on a concept card to reveal its definition
- Only one definition appears at a time for a clean learning flow
- Responsive design for smaller screens
- Simple, beginner-friendly JavaScript behavior

## Project Structure

- `index.html` – main page structure
- `css/assignment.css` – styling for the layout and flashcards
- `javascript/javascript.js` – JavaScript logic for the interactive card toggling
- `images/` – image assets for the project

## Tools Used

The project was built using the following tools and technologies:

- Visual Studio Code – code editor used to write and manage the project
- HTML5 – for page structure and content
- CSS3 – for layout, styling, animations, and responsiveness
- JavaScript – for interactivity and flashcard behavior
- Google Fonts – typography used in the design
- GitHub – for repository hosting and version control
- Browser Developer Tools – for testing, debugging, and previewing the page

## How to Run the Project

1. Open the project folder in your code editor.
2. Open `index.html` in a browser.
3. Click on any JavaScript concept card to view its definition.
